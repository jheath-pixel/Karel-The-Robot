# Karel the Robot

Welcome to the Karel the Robot programming classroom.

This repository contains the lessons, assignments, examples, worlds, and programming tools used to learn Java through Karel.

## Student Workspace

Students will use GitHub Codespaces to:

- Write and edit Java programs
- Create and modify Karel classes
- Run programs
- Watch Karel execute in the graphical City
- Debug programs
- Create and test their own worlds
- Complete programming challenges

## Curriculum

The course begins with Karel and gradually transitions into Java programming concepts including:

- Objects and classes
- Methods
- Parameters and arguments
- Conditionals
- Loops
- Inheritance
- Variables
- Boolean logic
- Problem solving
- Java programming

## Repository Structure

- `src/` — Java programming lessons
- `assignments/` — Student assignment instructions
- `examples/` — Example programs
- `worlds/` — Karel worlds
- `lib/` — Becker Karel library
- `teacher/` — Teacher-only materials
- `tests/` — Automated assessment tools
- `scripts/` — Classroom environment scripts

## Getting Started

Open this repository in GitHub Codespaces and begin with the assigned lesson.
